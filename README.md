# depgraph

Инструмент визуализации графа зависимостей для менеджера пакетов NuGet (.NET).
Практическая работа «Конфигурационное управление», вариант 12.

## 1. Общее описание

Проект выполняется по этапам. Сейчас готов **этап 1**: минимальный CLI-прототип,
который читает настройки из INI-файла, проверяет их и выводит в формате
«ключ = значение». Сбор данных о зависимостях, построение графа и визуализация
будут добавлены на следующих этапах. Сторонние библиотеки и менеджеры пакетов
для получения зависимостей не используются.

Язык: Java 21, без внешних зависимостей (для тестов нужен JUnit 5).

## 2. Функции и настройки

Конфигурация хранится в INI-файле, секция `[depgraph]`:

| Ключ | Обязателен | Описание |
|---|---|---|
| `package_name` | да | Имя анализируемого пакета. Идентификатор NuGet (буквы, цифры, `.`, `_`, `-`); в тестовом режиме только большие латинские буквы `A-Z` |
| `repository` | да | URL репозитория (`http://` или `https://`) или, при `test_mode = true`, путь к файлу тестового репозитория |
| `test_mode` | да | Режим работы с тестовым репозиторием: `true`/`false` (также `yes/no`, `on/off`, `1/0`) |
| `package_version` | да | Версия пакета: `13.0.3`, `1.2.3.4`, `1.0.0-beta.1` |
| `filter_substring` | нет | Пакеты, в имени которых есть эта подстрока, будут пропущены при анализе |

Синтаксис INI: секции `[имя]`, пары `ключ = значение`, комментарии отдельной
строкой (`;` или `#`). Ключи не зависят от регистра, повторы запрещены.

Обработка ошибок (сообщение в stderr, код завершения 1): файл не найден или это
каталог, не читается или не UTF-8, нарушен синтаксис INI (с номером строки),
нет секции `[depgraph]`, неизвестный или пропущенный ключ, пустое значение,
неверные `test_mode`, имя пакета, URL, путь к тестовому репозиторию, версия.

Аргумент командной строки: путь к INI-файлу (по умолчанию `config.ini` в текущей папке).

## 3. Сборка и тесты

Запуск (сборка и старт): `run.bat` (Windows) или `./run.sh` (Linux/macOS).

Ручная сборка:

    javac -encoding UTF-8 -d out src/*.java

Тесты (JUnit 5, `junit-platform-console-standalone.jar` положить рядом):

    javac -encoding UTF-8 -d out -cp junit-platform-console-standalone.jar src/*.java tests/*.java
    java -jar junit-platform-console-standalone.jar -cp out --scan-classpath

В IntelliJ IDEA: папка `src` помечена как Sources, `tests` как Test Sources.

## 4. Примеры использования

    > run.bat
    package_name = Newtonsoft.Json
    repository = https://api.nuget.org/v3/index.json
    test_mode = false
    package_version = 13.0.3
    filter_substring = Test

Ошибки (примеры файлов в `examples/errors`, запуск всех: `scripts/demo_errors.bat`):

    > run.bat examples\errors\bad_url.ini
    Ошибка конфигурации: repository: ожидается URL http(s)://хост/..., получено 'ftp://example.com'

    > run.bat nope.ini
    Ошибка конфигурации: файл конфигурации не найден: nope.ini
